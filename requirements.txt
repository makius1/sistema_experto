# Dependencias del proyecto

# Python: diccionarios, listas, condicionales y ciclos. No requieren paquetes
# externos, y esa es una decisión de diseño: el motor de inferencia se
# implementa desde cero para comprender su funcionamiento interno.
#
# Este archivo se mantiene en el repositorio porque:
#   1. Documenta explícitamente que no hay dependencias ocultas.
#   2. El devcontainer lo ejecuta al crear el entorno (postCreateCommand).
#   3. Cuando una sesión posterior requiera una librería, se agrega aquí con
#      su versión fijada y el entorno queda reproducible para cualquiera.
#
